# Requirements — €10,000 Digital Ops Package

Honest packaged scope from the firm catalog (not a mock).  
Currency for this campaign: **EUR 10,000** fixed.

## What is included
1. **Conversion landing page** — one responsive page, agreed offer, CTA/form wired to your endpoint  
2. **Approved workflow automation** — one named process (e.g. missed-call / after-hours inquiry → SMS or email follow-up with booking link), under your credentials, with audit log  
3. **Narrow software fix** (optional third slice) — one bounded patch in an existing site/tool if needed to wire the above

## What is not included
- Full multi-page CMS rebuilds, native mobile apps, model training, DeFi/trading bots  
- CAPTCHA/identity bypass, scraping behind logins, account rental  
- Ongoing ads/SEO retainers  
- Invented FX: invoices stay in the agreed currency (EUR for this package)

## Timebox
- ~15 business days after brief + assets + revocable tool access  
- Milestone acceptance in writing after each slice preview

## Acceptance
- Landing loads on mobile/desktop and matches the brief  
- Automation test run succeeds on a sample payload  
- Owner accepts each milestone in writing before the next starts

## Start checklist
1. One primary offer sentence  
2. Logo + photos (or placeholder permission)  
3. Lead destination (inbox / CRM / booking link)  
4. Tools for the automation (phone/SMS/CRM)  
5. Written go-ahead on this €10,000 package
