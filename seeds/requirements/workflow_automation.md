# Requirements — Approved workflow automation

Honest scope from the firm offer catalog (`workflow_automation`). Not a mock brief.

## Buyer problem
A repetitive approved process (missed call → follow-up, email → CRM, triage → notify) drops leads when nobody is at the desk.

## In scope
- Documented automation with named triggers and outputs
- Implementation in an agreed tool (n8n, Zapier, or small custom) under **owner credentials**
- Audit log of runs on a sample payload

## Out of scope
- CAPTCHA / identity bypass
- Scraping behind login walls
- Account rental or unauthorized access
- Replacing licensed staff judgment without an approval step

## Price and timebox
- USD 2,000–8,000 depending on integrations
- Typical delivery: 10 days after access + sample payloads

## Acceptance
- Each step has a clear trigger and output
- Test run succeeds on a sample payload
- Owner credentials are never stored in our repo

## What we need from you to start
1. The exact workflow in one paragraph (trigger → steps → desired outcome)
2. Tools you already use (phone carrier, SMS, CRM, calendar)
3. Temporary owner-granted access (revocable)
4. One human approval step you want kept (we recommend keeping it)
